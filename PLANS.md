# MVP Implementation Plan

1. Establish the native background-agent project and menu bar lifecycle.
2. Capture mouse gestures and read selected text through Accessibility APIs.
3. Add Google Cloud Translation, Keychain storage, and bounded caching.
4. Coordinate automatic translation and present results in a floating panel.
5. Add settings, permission guidance, launch at login, and OCR fallback.
6. Verify idle behavior and end-to-end outcomes in representative applications.

Each completed implementation step is committed independently on the feature
branch.
